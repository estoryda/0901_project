## 2. 디자인 시스템 (Design System)

### 2.1 컬러 팔레트 (CSS Variables)

| 변수명 | 라이트 모드 (Light Mode) | 다크 모드 (Dark Mode) | 용도 |
|---|---|---|---|
| `--bg-primary` | `#F8FAFC` (화이트 계열) | `#0F172A` (딥 네이비/다크) | 메인 배경색 |
| `--bg-surface` | `#FFFFFF` (순백색 카드) | `#1E293B` (어두운 슬레이트) | 카드, 네비게이션, 모달 배경 |
| `--text-primary` | `#0F172A` (진한 텍스트) | `#F8FAFC` (밝은 텍스트) | 기본 본문 및 헤드라인 |
| `--text-secondary` | `#64748B` (그레이) | `#94A3B8` (라이트 그레이) | 부가 설명, 날짜, 서브텍스트 |
| `--accent-color` | `#3B82F6` (모던 블루) | `#60A5FA` (브라이트 블루) | 브랜드 대표 포인트 컬러, 링크, 활성 탭 |
| `--accent-hover` | `#1D4ED8` | `#3B82F6` | 버튼 및 링크 호버 상태 |
| `--border-color` | `#E2E8F0` | `#334155` | 구분선 및 카드 테두리 |

### 2.2 타이포그래피 (Typography)
- **기본 폰트 패밀리**: `'Pretendard', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`
- **코드/기술 폰트**: `'Fira Code', 'JetBrains Mono', Consolas, monospace`
- **사이즈 계층**:
  - `h1` (Hero Title): `2.5rem ~ 3.5rem` (반응형 폰트 크기 `clamp()` 적용)
  - `h2` (Section Title): `2.0rem ~ 2.25rem`
  - `h3` (Card/Subtitle): `1.25rem ~ 1.5rem`
  - `body` (본문): `1rem (16px)`, `line-height: 1.6`
  - `caption / tag` (캡션/태그): `0.875rem (14px)`

## 3. 반응형 브레이크포인트 (Responsive Breakpoints)

- **Mobile (모바일)**: `< 768px`
  - 1열(Single Column) 카드 배치
  - 헤더 메뉴는 햄버거 토글 드롭다운으로 전환
  - 좌우 여백 패딩 축소 (`16px ~ 20px`)
- **Tablet (태블릿)**: `768px ~ 1024px`
  - 2열 그리드(Grid) 레이아웃
  - 네비게이션 메뉴 일반 표시 또는 압축 표시
- **Desktop (데스크톱)**: `> 1024px` (최대 너비 `max-width: 1200px` 중앙 정렬)
  - 2~3열 프로젝트 카드 그리드
  - 넉넉한 여백과 인터랙션 효과 극대화

---

## 4. 애니메이션 및 모션 가이드
1. **헤더 페이드인 & 스크롤 감지**: 스크롤 다운 시 배경 블러(`backdrop-filter: blur()`) 및 섀도우 적용
2. **섹션 등장 애니메이션**: 스크롤하여 화면에 진입할 때 부드러운 Fade-in + Slide-up 효과 (`IntersectionObserver` 활용)
3. **호버 인터랙션**: 버튼 및 프로젝트 카드에 마우스 오버 시 미세한 Y축 이동(`transform: translateY(-5px)`) 및 그림자 강조
