# 01. 요구사항 및 기능 정의서 (Requirements Specification)

## 1. 프로젝트 개요
- **프로젝트명**: Personal Profile & Portfolio Website
- **목적**: 개발자/기획자/디자이너 등 본인의 역량, 보유 기술, 프로젝트 이력 및 연락처를 직관적이고 매력적으로 전달하는 반응형 개인 웹페이지 구축
- **핵심 기술 스택**: HTML5, CSS3, Vanilla JavaScript (외부 프레임워크 없는 순수 웹 표준 기술)

---

## 2. 주요 페이지 구성 및 섹션 정의

| 섹션 번호 | 섹션명 | 주요 내용 |
|---|---|---|
| **01** | **Header / Navigation** | 로고/이름, 네비게이션 메뉴 (각 섹션 이동 링크), 다크모드 토글 버튼, 모바일 햄버거 메뉴 |
| **02** | **Hero Section (홈)** | 본인 한 줄 슬로건, 직무 타이틀(타이핑 애니메이션), 프로필 이미지, 이력서 다운로드/Contact 바로가기 CTA 버튼 |
| **03** | **About Me (소개)** | 본인 소개글, 핵심 가치/강점, 기본 인적사항(이름, 지역, 이메일, 경력 연수 등), GitHub/LinkedIn 등 소셜 링크 |
| **04** | **Skills (보유 기술)** | 프론트엔드/백엔드/협업 툴 등 카테고리별 기술 스택 아이콘, 숙련도 게이지 또는 배지 태그 |
| **05** | **Projects (프로젝트)** | 수행한 프로젝트 카드 목록, 기술 태그, 데모 링크, GitHub 저장소 링크, 상세 모달 팝업 |
| **06** | **Experience / Education** | 직무 경력 및 학력/수료 이력을 보여주는 시각적 타임라인(Timeline) |
| **07** | **Contact (문의)** | 연락처 정보(이메일 복사 기능), 간이 문의 폼(이름, 이메일, 메시지 입력) |
| **08** | **Footer** | 저작권 표기 (Copyright), 소셜 미디어 바로가기 아이콘, 맨 위로 가기(Top) 버튼 |

## 3. 기능적 요구사항 (Functional Requirements)

### 3.1 네비게이션 & 스크롤 인터랙션
- 사용자가 네비게이션 메뉴를 클릭하면 해당 섹션으로 부드럽게 스크롤 이동 (Smooth Scroll).
- 스크롤 위치에 따라 현재 보고 있는 섹션의 메뉴 항목이 자동으로 강조(Active 상태 표시 - Scrollspy).
- 페이지 스크롤 시 상단에 현재 읽기 진행도를 나타내는 스크롤 프로그레스 바(Scroll Progress Bar) 제공.
- 일정 이상 스크롤 시 우측 하단에 'Top 이동' 플로팅 버튼 활성화.

### 3.2 테마 모드 (다크/라이트 모드)
- 사용자의 OS 기본 테마 설정(`prefers-color-scheme`) 감지 및 초기 적용.
- 헤더의 토글 스위치로 다크모드/라이트모드 수동 전환 가능.
- `localStorage`를 활용하여 새로고침 또는 재방문 시에도 사용자가 선택한 테마 유지.

### 3.3 프로젝트 필터링 및 상세 보기
- 프로젝트를 분류별(예: All, Frontend, Backend, Fullstack, Toy Project)로 필터링할 수 있는 탭 버튼 제공.
- 프로젝트 카드 클릭 시 상세 설명, 스크린샷, 사용 기술 등을 볼 수 있는 모달 팝업(Modal) 지원.

### 3.4 연락처 & 인터랙션
- 이메일 주소 클릭 시 원클릭 클립보드 복사 기능 및 복사 완료 알림 툴팁(Toast).
- 문의 폼 입력값 유효성 검증(이메일 포맷, 필수값 체크 등) 및 제출 피드백.

## 4. 비기능적 요구사항 (Non-Functional Requirements)

1. **반응형 웹 디자인 (Responsive Web Design)**:
   - 모바일(320px~), 태블릿(768px~), 데스크톱(1024px~) 모든 해상도에서 완벽하게 동작.
   - 모바일 환경에서는 햄버거 메뉴 및 터치 친화적 UI 제공.
2. **웹 표준 및 시맨틱 마크업**:
   - `header`, `nav`, `main`, `section`, `article`, `footer` 등 적절한 시맨틱 태그 활용으로 SEO 및 스크린 리더 접근성 향상.
3. **성능 및 가벼움**:
   - 무거운 외부 라이브러리 사용을 지양하고 순수 CSS & JS로 구현하여 1초 미만의 빠른 로딩 보장.
